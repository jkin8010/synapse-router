# CLI Command Reference

Synapse CLI 是 Router 的开发者工具入口。所有协商、路由、账单管理都在 CLI 中完成。

## 命令概览

| 命令 | 描述 |
|------|------|
| [`synapse connect`](/docs/cli#connect) | 连接指定 Provider 并执行一个功能 |
| [`synapse setup`](/docs/cli#setup) | 交互式初始化向导 |
| [`synapse config`](/docs/cli#config) | 配置管理（点号记法） |
| [`synapse billing`](/docs/cli#billing) | 账单管理与配额查看 |
| [`synapse route`](/docs/cli#route) | 多维评分路由 |
| [`synapse evolve`](/docs/cli#evolve) | 生成零依赖 SDK |
| [`synapse pack`](/docs/cli#pack) | 管理 Provider Pack |
| [`synapse vault`](/docs/cli#vault) | 管理加密 API Key |
| [`synapse lock`](/docs/cli#lock) | 管理 Schema Lock |

> 各命令的详细用法将在后续版本中完善。
