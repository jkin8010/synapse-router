Cover these commands (extract accurate signatures from the CLI source code):

1. **connect** — Connect to a provider and execute a feature
   - Signature: `synapse connect <provider> <intent> [--input <json>] [--billing <strategy>]`
   - Example: Connect to DeepSeek for chat

2. **setup** — Interactive first-time setup wizard
   - Signature: `synapse setup`
   - Example: Run setup wizard to configure first provider

3. **config** — Manage configuration
   - Signature: `synapse config set|get|list [key] [value]`
   - Example: Set and get config values

4. **billing** — Billing management
   - Signature: `synapse billing init|config|status [options]`
   - Subcommands: init (interactive wizard with --strategy/--limit/--provider flags), config (view/modify), status (quota summary)
   - Example: Init billing, check quota status

5. **route** — Multi-dimensional provider routing
   - Signature: `synapse route <intent> [--strategy <strategy>] [--exclude <providers>] [--region <region>] [--min-version <version>]`
   - Strategies: cheap, fast, quality, balanced, cost-capped
   - Example: Route chat intent with quality strategy

6. **evolve** — Generate zero-dependency SDK from provider packs
   - Signature: `synapse evolve [--output <dir>] [--tune] [--with-billing]`
   - Example: Evolve SDK with billing tracking

7. **pack** — Manage provider packs from Registry
   - Signature: `synapse pack add|search|list|update|remove|show [options]`
   - Example: Search and install a pack from Registry

8. **vault** — Manage encrypted API keys
   - Signature: `synapse vault set|list|get|remove|verify|rotate`
   - Example: Store and retrieve API keys with base_url config

9. **lock** — Manage Schema Locks
   - Signature: `synapse lock list|show|remove|migrate|outdated`
   - Example: List existing locks, detect outdated locks

For each command:
- Full signature with subcommands
- Parameter descriptions
- 1-2 realistic usage examples with expected output/behavior
- Cross-references to related commands

# Synapse Router Skill

面向 AI Agent 的受控 Schema 协商与多 Provider 路由层。

## 快速开始

安装 skill:
- Claude Code: 项目根目录 CLAUDE.md 自动加载
- Cursor: 复制 `skills/cursor/.cursorrules` 到项目根
- Codex: 配置 `skills/codex/agent.yaml`

npm 安装: `npm install @synapse-router/skill`

GitHub raw URL 安装: `skills add https://raw.githubusercontent.com/qise-tech/synapse-router/main/skill.md`

## 核心能力

1. **Schema 协商**: 匹配 Agent Intent 到 Provider Feature，验证能力契约
2. **Provider 路由**: 五维评分选择最优 Provider
3. **SDK 生成**: `synapse evolve` 生成零依赖 TypeScript/Python SDK
4. **Billing 集成**: 配额管理、定价策略、自动包裹
5. **加密密钥管理**: AES-256-GCM 加密存储

## 命令速查

| 命令 | 用途 |
|------|------|
| `synapse connect <provider> <intent>` | 连接 Provider 执行功能 |
| `synapse evolve` | 生成零依赖 SDK |
| `synapse route <intent>` | 多维评分路由 |
| `synapse billing init` | 初始化计费配置 |
| `synapse billing status` | 查看配额和费用概览 |
| `synapse vault set <provider> <key>` | 存储加密 API Key |
| `synapse lock list` | 查看 Schema Lock 列表 |

完整命令参考: [CLAUDE.md](./CLAUDE.md#synapse-cli)

## 架构原则

- **开发时协商，运行时无感**: 复杂逻辑在开发时完成，运行时只有纯代码 SDK
- **SDK 零依赖**: 生成的 SDK 不依赖 @synapse-router/*
- **无运行时 LLM**: 运行时路径零 Token 成本
- **Provider 可替换不等价**: Adapter 诚实暴露能力，Router 按契约匹配

## 更多信息

- 文档: docs/API.md, docs/PACKS.md
