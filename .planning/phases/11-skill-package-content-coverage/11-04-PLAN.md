```yaml
# Synapse Router — Codex Agent Configuration
name: synapse-router
description: >
  Synapse Router is a controlled Schema negotiation and multi-Provider routing
  layer for AI Agents. It ensures every request has an explicit contract before
  execution. Core philosophy: "negotiate at dev time, zero-overhead at runtime."

version: "0.1.0"
repository: https://github.com/qise-tech/synapse-router

commands:
  connect:
    description: Connect to a provider and execute a feature
    usage: synapse connect <provider> <intent> [--input <json>] [--billing <strategy>]
    examples:
      - synapse connect deepseek chat --input '{"messages":[{"role":"user","content":"Hello"}]}'
      - synapse connect openai chat --billing cost-capped

  setup:
    description: Interactive first-time setup wizard
    usage: synapse setup
    examples:
      - synapse setup

  billing:
    description: Billing configuration and quota management
    subcommands:
      init:
        usage: synapse billing init [--strategy flat|per-token|per-unit|tiered] [--limit <n>] [--provider <id>]
        examples:
          - synapse billing init --strategy per-token --limit 10000 --provider openai
      config:
        usage: synapse billing config
        examples:
          - synapse billing config
      status:
        usage: synapse billing status
        examples:
          - synapse billing status

  route:
    description: Multi-dimensional provider routing
    usage: synapse route <intent> [--strategy cheap|fast|quality|balanced|cost-capped] [--exclude <id>] [--region <region>]
    examples:
      - synapse route chat --strategy quality
      - synapse route text-to-image --strategy fast --region us-east

  evolve:
    description: Generate zero-dependency SDK from all provider packs
    usage: synapse evolve [--output <dir>] [--tune] [--with-billing]
    examples:
      - synapse evolve --output ./generated-sdk --with-billing

  vault:
    description: Manage encrypted API keys
    subcommands:
      set:
        usage: synapse vault set <provider> <key> [--base-url <url>] [--pack <id>]
        examples:
          - synapse vault set openai sk-xxx --base-url https://api.openai.com/v1
      list:
        usage: synapse vault list
        examples:
          - synapse vault list
      get:
        usage: synapse vault get <provider>
        examples:
          - synapse vault get openai

  lock:
    description: Manage Schema Locks
    subcommands:
      list:
        usage: synapse lock list
        examples:
          - synapse lock list
      outdated:
        usage: synapse lock outdated
        examples:
          - synapse lock outdated

  pack:
    description: Manage provider packs from Registry
    usage: synapse pack add|search|list|update|remove|show
    examples:
      - synapse pack search openai
      - synapse pack add openai/chat

  config:
    description: Manage Synapse Router configuration
    usage: synapse config set|get|list [key] [value]
    examples:
      - synapse config set route.strategy quality
      - synapse config get route.strategy

preferences:
  default_strategy: balanced
  output_format: json
  billing_behavior: warn

context:
  tech_stack:
    language: TypeScript 5.9+ (strict mode)
    runtime: Node.js 22+
    package_manager: pnpm 10+
    test_runner: Node.js native test runner (tsx --test)
  architecture_principles:
    - "Contract before call — always define Schema contract first"
    - "Negotiate at dev time, zero overhead at runtime"
    - "No runtime LLM — zero token cost at runtime"
    - "SDK zero-dependency — generated code uses only native fetch"
    - "Wrapper pattern — wrap connectors, never modify internals"
    - "Vault never writes plaintext — AES-256-GCM encryption"
```

```markdown
# Synapse Router — OpenClaw Agent

You are an AI agent working with Synapse Router, a TypeScript monorepo for controlled Schema negotiation and multi-Provider routing.

## Project Purpose

Synapse Router sits between AI Agents and multiple Provider APIs. Its core job: ensure every API call has an explicit contract before execution. It provides CLI tools, an HTTP API, MCP Server, and SDK generation.

## Technology

- TypeScript 5.9+ (strict mode) / Node.js 22+ / pnpm 10+
- Zero external runtime dependencies — raw node:http, node:fs, node:crypto
- Generated SDKs use only native fetch, no @synapse-router/* imports
- Tests: Node.js native test runner (tsx --test), co-located with source

## Key Commands

| 命令 | 用途 |
|------|------|
| `synapse connect <provider> <intent>` | 连接 Provider 执行功能 |
| `synapse evolve` | 生成零依赖 SDK |
| `synapse route <intent>` | 多维评分路由 |
| `synapse billing init` | 初始化计费配置 |
| `synapse billing status` | 查看配额和费用概览 |
| `synapse vault set <provider> <key>` | 存储加密 API Key |
| `synapse lock list` | 查看 Schema Lock 列表 |

4. **Billing**: Help configure and monitor API usage billing.
```
