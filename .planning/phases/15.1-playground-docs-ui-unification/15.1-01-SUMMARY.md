# Phase 15.1 Plan 01: Playground Zinc/Emerald Color Unification Summary

**One-liner:** Replaced all gray-* and blue-* Tailwind color classes across 17 Playground source files with zinc-* (surface/palette) and emerald-* (accent) matching the synapse-registry design system.

## Objective

Replace all gray-* and blue-* Tailwind color classes in the Playground with zinc-* and emerald-* matching the synapse-registry design system. Purpose: Unify Playground visual style with the synapse-registry zinc palette per D-15.1-01 through D-15.1-07.

## Key Results

- **Gray-850 custom color removed** from index.css @theme block -- now uses Tailwind v4 built-in zinc-900
- **Zero gray-* classes** in any Playground source file (17 files, 95 zinc-* references created)
- **Zero blue-* classes** in any Playground source file (23 emerald-* references created)
- **Kbd styles** updated from gray RGB values to zinc equivalents (rgb(161,161,170)/rgb(63,63,70)/rgb(82,82,91))
- **Active kbd** updated from gray-300 to zinc-300 (rgb(212,212,216))
- **Primary accent** is emerald-400 for selections, active tabs, primary button bg/text
- **Button backgrounds** use emerald-500 (darker variant)
- **Hover text** uses emerald-300
- **Divider hover** uses emerald-500/20 opacity
- **Status dot** uses emerald-400 active / zinc-500 idle

## Task Details

### Task 1: CSS foundation
Removed the `--color-gray-850: #1a1d24` custom color from the `@theme` block in index.css. Updated kbd element RGB color values from gray palette:
- Default: gray-400 (#9CA3B5) to zinc-400 (#A1A1AA), gray-700 (#374151) to zinc-700 (#3F3F46), gray-600 (#4B5563) to zinc-600 (#52525B)
- Active: gray-300 (#D1D5DB) to zinc-300 (#D4D4D8)

### Task 2: Bulk gray to zinc
Ordered sed replacements:
1. First: `gray-850` -> `zinc-900` (prevents invalid `zinc-850`)
2. Then: bulk `gray-` -> `zinc-` (1:1 mapping for all standard shades 50-950)

### Task 3: Blue to emerald
Ordered sed replacements with specific shade mappings:
1. `hover:bg-blue-500/30` -> `hover:bg-emerald-500/20` (decision D-15.1-06)
2. `bg-blue-600` -> `bg-emerald-500` (darker button variant)
3. `blue-500` -> `emerald-400` (primary accent)
4. `blue-400` -> `emerald-400` (tab active, status indicator)
5. `blue-300` -> `emerald-300` (hover text state)
6. Catch-all `blue-` -> `emerald-` (any remaining shade)
