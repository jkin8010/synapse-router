## Target billing-config.json schema (IRREVERSIBLE design decision):
```json
{
  "version": "1",
  "providers": {
    "<providerId>": {
      "pricing": {
        "<featureId>": {
          "strategy": "perToken",
          "unit": "1k tokens",
          "inputPrice": 0.0015,
          "outputPrice": 0.002
        }
      },
      "quotas": [
        {
          "id": "<providerId>-cost-quota",
          "type": "cost",
          "limit": 10,
          "used": 0,
          "period": "month",
          "threshold": 0.8
        }
      ],
      "onError": "warn"
    }
  }
}
```
Each provider entry in `providers` is a `BillingConnectorConfig` minus `providerId` (the key IS the providerId). Callers combine: `{...billingConfig.providers[providerId], providerId}` to get a full `BillingConnectorConfig`.

**D. handleBillingInit(argv: string[])** -- The init wizard:

D1. Parse flags from argv:
```
providers: string[] = []              // accumulate from repeated --provider flags
pricingStrategyFlag: string | undefined  // --pricing-strategy X
quotaFlag: number | undefined           // --quota N (parseFloat)
quotaPeriodFlag: string | undefined     // --quota-period X
onErrorFlag: string | undefined         // --on-error X
```
Loop: if `--provider` → push next arg; if `--pricing-strategy` → store next arg; if `--quota` → parseFloat next arg; if `--quota-period` → store next arg; if `--on-error` → store next arg; if `--help` or `-h` → printBillingHelp() and return.

D2. Interactive wizard (when `providers.length === 0`):
```
a. const packsDir = await findPacksDir()
b. const installed = await listInstalledProviders(packsDir)
c. If installed.length === 0: print "No provider packs found. Run 'synapse pack add <provider>' first." → process.exit(1)
d. Show numbered list: "Available providers:" → each as "{i+1}. {name} ({id})"
   Add option: "{installed.length+1}. All providers"
e. Use readline.createInterface to prompt: "Select provider (enter number): "
f. Parse selection: if last option → all providers; else → selected provider by index
g. For each selected provider:
   i.   Load full ProviderCard via loadProviderCard(packsDir, providerId)
   ii.  Print: "\nConfiguring {providerName} ({providerId}) - {featureCount} features"
   iii. For each feature in card.features:
        - Call: const defaultRule = pricingFromProviderCard(feature.pricing)
        - Print detected pricing:
          "  Feature: {feature.id} ({feature.intent})"
          "    Detected: {strategy} | unit={unit} | inputPrice={inputPrice} outputPrice={outputPrice} unitPrice={unitPrice} costPerCall={costPerCall}"
        - Prompt with readline: "    Accept? [Y/n/custom]: "
        - If '' or 'Y' or 'y': store defaultRule keyed by feature.id
        - If 'n' or 'N': skip this feature (no billing tracking)
        - If 'custom':
          - Prompt strategy: "      Strategy (perToken/perUnit/flat): " → validate against union
          - If perToken: prompt "      Input price per 1k tokens: " → parseFloat, prompt "      Output price per 1k tokens: " → parseFloat
          - If perUnit: prompt "      Unit name (e.g., 'per image'): " → string, prompt "      Price per unit: " → parseFloat
          - If flat: prompt "      Cost per call: " → parseFloat
          - Build custom PricingRule and store
   iv.  After features: prompt for quota:
        - "    Quota limit in USD (default: 10): " → parseFloat || 10
        - "    Quota period (hour/day/month, default: month): " → validate: must be hour|day|month, default 'month'
        - "    Error handling (warn/reject, default: warn): " → validate: must be warn|reject, default 'warn'
        - Create Quota: { id: "{providerId}-cost-quota", type: "cost", limit: userValue, used: 0, period: userPeriod, threshold: 0.8 }
   v.   Build provider config entry with pricing map + quotas array + onError
h. Close readline interface
```

D3. Non-interactive mode (when `providers.length > 0`):
```
For each providerId in providers:
  a. Load ProviderCard. If not found: console.error + process.exit(1)
  b. For each feature: pricingFromProviderCard(feature.pricing) → PricingRule
     If pricingStrategyFlag is set: override rule.strategy with flag value
  c. Create Quota with flag values or defaults: limit=quotaFlag||10, period=quotaPeriodFlag||'month', threshold=0.8
  d. onError = onErrorFlag || 'warn'
  e. Build provider config entry
```

D4. Validate flag values immediately when parsed (before any wizard/file I/O):
- `pricingStrategyFlag`: must be 'perToken' | 'perUnit' | 'tiered' | 'flat', else print "Invalid pricing strategy: '{value}'. Use: perToken, perUnit, tiered, flat" + process.exit(1)
- `quotaPeriodFlag`: must be 'hour' | 'day' | 'month', else print "Invalid quota period: '{value}'. Use: hour, day, month" + process.exit(1)
- `onErrorFlag`: must be 'warn' | 'reject', else print "Invalid on-error strategy: '{value}'. Use: warn, reject" + process.exit(1)
- `quotaFlag`: if present and isNaN after parseFloat, print "Invalid quota value: '{value}'. Must be a number." + process.exit(1)

await mkdir(join(homedir(), ".synapse"), { recursive: true });

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User input -> CLI process | Command-line arguments and readline input cross into Node.js process |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-01 | Tampering | billing-config.json write | mitigate | Use JSON.stringify with structured object (no string concatenation). Write to fixed path `~/.synapse/billing-config.json` -- no user-controlled path component. |
| T-10-02 | Spoofing | Provider card loading | mitigate | Only load provider-card.json from directories that pass `!entry.name.startsWith(".")` filter. Validate `card.provider.id` exists before using. |
| T-10-03 | Information Disclosure | billing-config.json contents | accept | Billing config contains pricing/quotas -- not PII or secrets. Stored in user's home directory with default OS file permissions. |
| T-10-04 | Denial of Service | Interactive readline | accept | Readline prompts are sequential and user-driven. No unbounded loops -- wizard has finite steps (providers x features). |
| T-10-05 | Elevation of Privilege | Flag parsing | mitigate | Validate all flag values against union types: `PricingStrategy` must be one of `perToken\|perUnit\|tiered\|flat`, `QuotaPeriod` must be `hour\|day\|month`, `BillingOnError` must be `warn\|reject`. Reject invalid values with error message + exit(1). |
| T-10-06 | Repudiation | billing-config.json write | accept | No audit log needed for local config file writes. Accept risk. |
</threat_model>
