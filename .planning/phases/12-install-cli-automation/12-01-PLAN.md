    2. `export async function installSkill(options: InstallOptions): Promise<void>`:

    **Phase 1: Resolve paths** — call `resolveInstallInfo(platform as Platform, cwd, home, customDir)` to get `InstallInfo`.

    **Phase 2: Build manifest entries** — create `ManifestEntry[]` in memory:
    - For claude-code (isDirectoryTarget=true): source = `SOURCE_FILES[platform]` (e.g. `"claude-code/skill.md"`). target = `join(targetPath, TARGET_NAMES[platform])` (e.g. `"/cwd/.claude/skills/synapse-router/SKILL.md"`).
    - For other platforms (isDirectoryTarget=false): source = `SOURCE_FILES[platform]`, target = targetPath directly (targetPath is already the full file path).

    **Phase 3: Dry run** — if `dryRun: true`, print formatted plan and return (do not touch filesystem):
    ```

    Would copy 1 file(s):
      skills/claude-code/skill.md -> /path/to/.claude/skills/synapse-router/SKILL.md
    Would write install manifest: /path/to/.synapse/install-manifest.json
    ```

    **Phase 4: Backup** — for each entry, check if target already exists using `await access(target)` from `node:fs/promises`. If exists:
    - backupDir = `join(synapseDir, "install-backups")`
    - backupName = `"backup-" + Date.now() + "-" + basename(target)`
    - backupPath = `join(backupDir, backupName)`
    - `await mkdir(dirname(backupPath), { recursive: true })`
    - `await copyFile(target, backupPath)`
    - Set entry.backup = backupPath
    - If backup fails at any point, throw immediately — do NOT proceed to copy phase

    **Phase 5: Copy** — for each entry:
    - sourcePath = `join(skillsDir, entry.source)`
    - `await mkdir(dirname(entry.target), { recursive: true })` (prevents ENOENT if `.claude/skills/synapse-router/` doesn't exist)
    - `await copyFile(sourcePath, entry.target)`
    - If ANY copy fails: throw immediately with the error. Do NOT write manifest. (Pitfall 3: all-or-nothing)

    **Phase 6: Write manifest** — only after ALL copies succeed:
    - Build `InstallManifest`: `{ version: "1" as const, createdAt: new Date().toISOString(), packageVersion: "0.1.0", platform: platform, files: manifestEntries }`

    Synapse Router Skill installed for claude-code!
      Installed 1 file(s)

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI args -> install-skill | User-supplied --platform and --dir values enter the program and control file system operations |
| File system -> install-skill | Existing files at target paths could be symlinks. Manifest files could be corrupted by external modification |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-01 | Tampering | --dir path traversal in resolveInstallInfo | mitigate | Validate that resolved customDir stays within cwd or homedir() boundary. Reject paths containing `..` segments that escape the allowed root. Check `resolvedPath.startsWith(allowedRoot)` before any file operation. Target path resolution is always relative to CWD or homedir per D-03. |
| T-12-02 | Tampering | Symlink following during backup/copy | mitigate | `copyFile` follows symlinks and copies target content rather than creating new symlinks. The backup destination is always inside `.synapse/install-backups/` which stays within CWD. Target paths come from the validated INSTALL_PATHS mapping, not from user input, so no symlink traversal outside permitted directories. |
| T-12-03 | Tampering | Malformed install manifest causing incorrect file deletion | mitigate | `readManifest()` wraps JSON.parse in try/catch and returns null on any parse error. `uninstallSkill()` only operates when manifest is valid JSON. Before deleting each file from the manifest, verify the file path starts with a known root (cwd or homedir) to prevent deletion of unrelated files. |
| T-12-04 | Tampering | Partial install — manifest written before all copies complete | mitigate | `installSkill()` writes manifest ONLY in Phase 6, AFTER all file copies succeed in Phase 5. If any copy fails, error is thrown before manifest write. Manifest uses atomic write (.tmp + rename) so crash during write cannot produce corrupted file. |
| T-12-05 | Denial of Service | Infinite recursion via nested .synapse/ detection | accept | `.synapse/install-backups/` and `.synapse/install-manifest.json` are always created under `{cwd}/.synapse/`. Target paths are hardcoded per platform (D-03), not derived from directory scanning. No risk of recursion. |
| T-12-06 | Information Disclosure | API keys or credentials in skill files | accept | Skill files contain only documentation and configuration — no secrets, API keys, or credentials. The install-skill package never reads or transmits user data. ASVS V6 (Cryptography) not applicable. |
