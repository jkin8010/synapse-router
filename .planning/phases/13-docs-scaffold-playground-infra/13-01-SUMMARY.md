## Deviations from Plan

### Rule 1 — Bug Fixes (auto-fixed)

**1. MDX HTML comment syntax**
- **Found during:** Build verification after Task 7
- **Issue:** HTML comments `<!-- -->` in `api.md` and `packs.md` are not valid in MDX; Docusaurus treats `.md` files as MDX
- **Fix:** Replaced with MDX comment syntax `{/* */}`
- **Files modified:** `apps/docs/docs/api.md`, `apps/docs/docs/packs.md`
- **Commit:** `652844b`

**2. useColorMode import path**
- **Found during:** Build verification after Task 7
- **Issue:** `@theme/hooks/useColorMode` is not resolvable in Docusaurus v3 classic preset
- **Fix:** Changed to `{useColorMode} from '@docusaurus/theme-common'` and added `@docusaurus/theme-common` as direct dependency
- **Files modified:** `apps/docs/src/pages/index.tsx`, `apps/docs/package.json`
- **Commit:** `652844b`

### Rule 2 — Missing Critical Functionality (auto-added)

**3. Root build:docs script**
- **Found during:** Plan objective review
