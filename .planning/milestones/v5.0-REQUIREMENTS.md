# Synapse Router -- Requirements v5.0

## Milestone v5.0: 交互式协商与体验优化

**Goal:** 完善 CLI 命令基础设施、实现交互式协商、精简命令结构、更新文档和 Playground UI

**范围：**
- CLI 基础设施：命令提取、共享 prompts、全局 flags
- 交互式协商：intent 选择、Schema 预览、字段开关、Lock diff
- 命令精简：help 文本集中化、命令合并
- 文档和 Playground：SDK 预览、Presets、费用预览
